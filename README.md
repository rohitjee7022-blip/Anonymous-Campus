# Anonymous Campus

**Speak honestly. Stay protected.**

Anonymous Campus is a privacy-first campus facility feedback platform designed to help students report facility problems while protecting their identities.

## Problem

Students may hesitate to report poor campus facilities because they fear their identities could be exposed. Administrators also need a better way to identify recurring problems and prioritize improvements.

## Solution

Anonymous Campus separates student authentication from feedback records and provides administrators with aggregated facility insights.

## Key Features

### Student Panel
- College email authentication.
- Anonymous facility ratings and feedback.
- Weekly feedback submission limits.
- Account notices and sanction appeals.

### Admin Panel
- Aggregated facility ratings and statistics.
- Recent student feedback management.
- Comment approval and withholding.
- Fair account moderation and appeal review.
- Facility issue tracking and status updates.

### BharatCode AI Integration
- Analyses aggregated facility ratings.
- Uses privacy-reviewed facility issue statistics.
- Generates insights and actionable recommendations.
- Does not receive raw student comments or identifying information.

## Technology Stack

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Functions
- BharatCode AI API

## Privacy Principles

- Student identity is separated from feedback.
- Raw student comments and identifying information are not sent to BharatCode AI.
- Negative ratings alone are not treated as policy violations.
- Comment moderation does not remove the associated rating.
- Students can appeal account sanctions.
